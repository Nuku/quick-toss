# Changelog

## 0.1.4

- Added MLP Dice Living Inside presets that animate during the toss and freeze on landing.

## 0.1.3

- Increased the on-screen dice size by 25%.
- Play recorded dice clatter through Foundry's native audio engine and wait for Foundry to unlock audio.

## 0.1.2

- Preloaded recorded clatter and added Foundry's stock dice sound for rolls while it loads.
- Increased recorded clatter volume while continuing to use Foundry's Interface volume.

## 0.1.1

- Added recorded dice clatter that follows Foundry's interface volume.
- Extended the settled dice display by one second. Chat still reveals as soon as the dice land.

## 0.1.0

- Added fixed-duration 3D dice tosses with a chat reveal on landing.
- Added per-player selection of Dice So Nice-compatible presets, themes, and textures from active add-ons.
- Added result display for percentile dice, Fate dice, and coins.
